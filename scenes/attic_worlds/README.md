# 阁楼四世界编辑入口

直接打开对应场景编辑，保存后重新运行主场景即可生效，无需重新烘焙。

| 文件 | 场景 | 盘外告示牌 |
| --- | --- | --- |
| cloud.tscn | 云海 | 这里真的是家吗？ |
| firefly.tscn | 树林点灯 | 伪装的温柔为我点了一盏灯。 |
| alley.tscn | 雨巷 | 逝者如斯夫，不会回来 |
| snow.tscn | 雪夜 | 这里真的是家吗？ |

选中 `StorySign` 移动整块牌子；在 `StorySign/Text` 的 Text 属性中修改文字。`PlayerSpawn` 控制出生点。

树木、灯光、模型、碰撞和平台都已保存为实际场景节点，可以直接调整位置、旋转、缩放和属性。导入模型可通过“可编辑子节点”调整内部节点。世界根节点 `Content` 保留了游戏使用的比例和偏移。

交互锚点、机关及其父节点的名称和层级用于连接游戏逻辑，请保留；移动时连同锚点一起移动。若删除或改名导致玩法引用缺失，运行时会发出警告并回退到程序生成版本。船和飞艇的运行轨迹仍由脚本控制。

`tools/bake_attic_worlds.gd` 仅用于首次创建源场景，遇到已有文件会拒绝覆盖。Windows/Web 成品需重新导出才能包含之后的编辑。
