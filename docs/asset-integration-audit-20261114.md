## 星球差异与道具落点

每颗星球保留各自地表模型、主次签名地标、生态和地貌组合。工坊按用途分为四类：

| 类型 | 星球 | 设备与结构 |
| --- | --- | --- |
| 野外 | 青岚、苔垣、苍梧、玄圃 | 制氧、补给、风力设施、管线 |
| 采矿 | 赭崖、磐砂、绛霄、金乌、丹霞 | 钻机、燃料设备、梯架、管线 |
| 极地与海洋 | 沧波、白曜、碧落、幽都 | 储存舱、信标、挡风板 |
| 观测 | 悬晶、玄渊、硫坞、缄默、玉衡、素娥、瑶光 | 通信、数据、控制设备及有立柱支撑的顶冠 |

模块共用切平面坐标。支脚和地面设备按地形高度落地；设备使用脚底实际顶点对齐甲板三角面。
楼梯按最高一级踏面接甲板边沿，顶冠立柱按曲面底面定高度。可通行构件使用同一网格变换生成碰撞。

修复同一模型在后续布置阶段追加却不显示的问题：按队列数量更新已有 MultiMesh，重建对应碰撞并保持交互索引绑定。
生成的低矮植物接入草量开关；LOD 和草量共同生效，后续加载的星球继承当前设置，地标不削减实例。

## 阁楼与口袋世界

地板精确拼接并有完整底板；屋顶坡向、山墙、门框与门扇接缝校准。
桌上物件、书架隔板上的纪念物按真实支撑面放置；地毯和手册调整朝向后按占地尺寸缩放。
唱片机增加柜体支撑，挂画避开门，旋钮、燕子飞行坐标和茶席反馈一并修正。
口袋世界按三个道具目录依次查找资源，补齐此前漏载的资产并保留互动状态和桥梁逻辑。
