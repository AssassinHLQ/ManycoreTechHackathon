# 程序化建模清单（2026-11-14）

本清单区分成套场景、建模模块和渲染网格。它们不是可以相加的三种模型数量。

## 主要场景：21 套

计数单位是有独立构建入口和空间边界的地标、洞穴或可探索场景。场景中的程序化主体结构可以搭配导入家具和装饰，因此这个数量不表示 21 个纯程序化、可独立导出的模型文件。

| 主体 | 数量 | 实际对象 / 构建来源 |
| --- | ---: | --- |
| 星球地标建筑群 | 10 | 青岚、赭崖、沧波、悬晶、玄渊、白曜、磐砂、苔垣、硫坞、缄默；`architecture.gd` |
| 地下洞穴 | 3 | 青岚、赭崖、悬晶；`underground.gd` |
| 归航站 | 1 | 外壳、旋转环、中央枢纽、六条走廊及舱室；`station.gd` |
| 阁楼 | 1 | 房间主体、屋顶、地板、门及互动结构；`attic.gd` |
| 口袋世界 | 6 | 雪夜、云海、萤火、雨巷、镜界、镜牢；`attic_worlds.gd` |
| 合计 | **21** | 完成 20 星球渐进建场后的实测对象与构建入口核对 |

两座远景站另有按需创建的程序化内部舱室，第一次进入时生成；不在开局常驻的 21 套之内。两座站的外观来自 GLB。20 颗星球目前也使用导入表面，代码仍负责地形处理、水体、大气、地表摆放及缺资源回退，不能把它们直接称为 20 个纯程序化模型。

## 建模代码：14 个模块

以下 14 个 `scripts/*.gd` 文件直接创建 PrimitiveMesh、ArrayMesh 或使用 SurfaceTool 构造网格。只做摆放、碰撞、材质或加载 GLB 的脚本不计。

| 文件 | 程序化内容 |
| --- | --- |
| `architecture.gd` | 10 类地标建筑及结构细节 |
| `underground.gd` | 洞穴、坡道、洞室及建筑内部构件 |
| `station.gd` | 归航站主体、走廊、门、舱室、内部结构及家具回退 |
| `distant_station_interior.gd` | 远景站环形观景舱、控制台、柱、长凳等 |
| `attic.gd` | 阁楼主体、门、镜廊、茶席、纪念架等，部分家具已有 GLB |
| `attic_worlds.gd` | 六个世界的主体、装置、桥、船、互动结构及资产缺失回退 |
| `planet.gd` | 程序化表面回退、水体、大气、云层、环及地表辅助结构 |
| `ship.gd` | 船体回退、机翼及推进焰等；当前主船体为导入模型 |
| `main.gd` | 恒星、日珥、彗星及其他环境几何 |
| `anomaly.gd` | 原始扫描信号的几何标识 |
| `quantum.gd` | 量子碎岩、晶体及环 |
| `route_echo.gd` | 四条联动路线的新回声投影 |
| `roast.gd` | 烘烤食物等手持几何 |
| `dungeon.gd` | 动态生成的镜影敌人、首领等 |

## 场景中的网格：2,735 个程序生成节点

使用 Godot 4.7.1 headless，等待 20 星球全部建场，保留生产环境静态合并，未进入远景站内部、未生成镜牢战斗敌人。遍历 MeshInstance3D 与 MultiMeshInstance3D，并根据导入场景来源、网格资源路径及 GLB 道具实例归属排除导入模型。隐藏但已创建的场景计入。

| 范围 | 程序生成网格节点 |
| --- | ---: |
| 行星子树（包含其地标、洞穴、停泊飞船特效等） | 1,495 |
| 归航站 | 715 |
| 阁楼 | 120 |
| 六个口袋世界 | 385 |
| 恒星及其细节层 | 16 |
| 彗星 | 4 |
| 合计 | **2,735** |

按网格类型校对：BoxMesh 1,055、CylinderMesh 778、ArrayMesh 536、SphereMesh 252、TorusMesh 109、QuadMesh 4、CapsuleMesh 1，合计一致。

这个数是渲染节点数，包含墙板、地板、管道、粒子外观和合并块，**不能称为 2,735 个独立模型**。归航站有 3,700 个原始网格节点进入四组合并，输出 255 个合并块；715 是合并块与未合并的程序生成节点共同组成的开局结果。站内家具另有导入模型，未混入程序化节点数。

动态敌人、稍后进入的远景站内部，以及缺失 GLB 时才出现的回退几何会改变运行时数量。碰撞 Shape、Label3D 和二维 UI 不计。原有资产清单里的生成道具属于导入资产，也不与上述数字相加。

实测明细：`_tools/_tmp/procedural_census.json`、`procedural_census_verified.log`（临时审计产物，不入库）。
