# 余晖回声 · StarwardWilds

一个第一人称太空探索原型：在微型太阳系里驾船、扫描遗迹、钻地下洞穴、低速对接原创环状空间站「归航站」并参观真实舷窗外的宇宙，并在 17 分钟一次的恒星爆发轮回中保留知识。

> 原创垂直切片。类型启发性地参考了包括 Outer Wilds 在内的探索类作品，烤棉花糖是唯一保留的具体玩法致敬；没有使用其名称、角色、剧情或素材。归航站的六廊中央枢纽布局参考了 Arknights 罗德岛等移动舰船的视觉组织方式，站名、舱室名、平面与美术均为原创。与原作、发行商及鹰角网络均无关联。

| 归航站 | 低速靠近对接口 24 米内且低于 18 m/s 自动对接 · E 进入站内 · Space 脱离对接 |

## 手机 / 触屏

- 手机浏览器会自动显示触屏层，无需额外设置；也可在地址后加 `?touch=1` 强制开启。
- 左侧摇杆移动 / 飞船平移，右侧空白拖动视角；右侧圆钮会根据徒步或飞船自动切换。
- 飞船圆钮：起飞 / 着陆 / 离船 / 上升 / 下降 / 加力 / 制动 / 自动航行；对接后切换为「进入空间站 / 脱离对接」。
- 站内使用「互动」按钮在中央枢纽气闸控制台返回飞船；左侧摇杆在六条放射走廊内移动。
- 星图右下角提供缩放、设为目标和关闭按钮，空白处拖动平移。
- 首次触摸会请求全屏并尝试锁定横屏，左上角「横屏全屏」按钮可手动重试；竖屏会被遮罩拦住，转到横屏后自动进入。
- Android Chrome 可强制横屏；iOS Safari 不允许网页锁定方向，需要手动旋转。

## 技术

- Godot 4.7.1（Compatibility / WebGL2，单线程导出，无需 COOP/COEP 头）
- 归航站的静态硬表面在启动时合并：走廊 1,497、枢纽 802、站外（外臂/主塔/端舱/检修车）1,403、外环细节 212 个 `MeshInstance3D` 按"材质签名 + 空间分块"烘焙成多材质网格（24 米 / 站外 60 米一块，六条走廊共享同一批资源）。全站网格节点 11,655 → 722、surface 11,660 → 2,636，飞到站点附近可绘制批次约 1,630 → 680。分块是为了灯光：兼容渲染器每个对象默认只能吃 8 盏灯，整条 213 米走廊合成一个对象会让门口发黑，因此长盒子按 24 米切段并把每对象灯上限提到 16。合并逐面核对了三角形数（与"含切段的预期值"完全相等）与法线长度，headless A/B 显示建场耗时 3,549 / 3,537 ms，几乎不变；碰撞、灯光、标签、旋转外环、可隐藏端舱与闪烁信标不受影响
- `index.wasm` 原始约 38 MB，gzip 后实际传输约 10.2 MB；`index.pck` 约 557 KB（570,212 字节）
- 已启用 Service Worker：首次加载后 wasm 会缓存到本地，第二次进入不再下载 wasm，只更新约 0.8 MB 的脚本与 pck
- 校园网限速时首次建议用流量/热点，或部署到 Cloudflare Pages / 国内对象存储
- 星球、地形、建筑、洞穴、量子规则与程序音频均为项目内程序化生成；环境音分深空床、站内底噪、行星风与远距无线电/金属应力单发，并走独立混响总线；枢纽放气门另有程序合成的位置音效（泄压嘶声 + 电机低鸣 + 到位顿挫），挂在门框上按距离衰减
- 网页版由浏览器控制分辨率与垂直同步；音频需首次点击后播放
- 网页版鼠标视角按 devicePixelRatio 归一化并乘 0.5 基础比例，单次事件限幅 120 px，避免指针锁定跳变导致高敏旋转
- 设置菜单支持画质预设、分辨率、帧率上限（30–240）、MSAA、阴影、视距、草地、主音量与鼠标灵敏度
