# 借一扇晴天

一个第一人称太空探索原型：在微型太阳系里驾船、扫描遗迹、钻地下洞穴、低速对接原创环状空间站「归航站」并参观真实舷窗外的宇宙，并在 17 分钟一次的恒星爆发轮回中保留知识。

> 原创垂直切片。类型与体验层面参考了包括 Outer Wilds 在内的探索类作品（限时轮回、恒星爆发、量化观测、篝火烤棉花糖等玩法母题）；**未使用**其名称、角色、剧情、地点、文本、美术或音频。归航站的六廊中央枢纽布局参考了 Arknights 罗德岛等移动舰船的视觉组织方式，站名、舱室名、平面与美术均为原创。与原作、发行商及鹰角网络均无关联。

## 操作

| 场景 | 按键 |
|---|---|
| 徒步 | WASD 移动 · 鼠标观察 · Space 跳跃 · Shift 喷气 · Ctrl 奔跑 |
| 徒步 | F 扫描 · 右键信号镜（滚轮 2.1×–16.9×） · L 头灯 · R 地形脱困 · E 登船 / 烤棉花糖 |
| 飞船 | 鼠标转向 · 滚轮长焦（1×–16×） · W/S 前后 · A/D 横向 · Space/Ctrl（或 C）垂直 · Shift 加力 · X 制动（耗推进剂） |
| 飞船 | Tab 切换目的地 · T 自动航行 / 着陆（按实际 Δv 耗推进剂） · E 着陆 / 离船 |
| 归航站 | 低速靠近对接口 24 米内且低于 18 m/s 自动对接 · E 进入站内 · Space 脱离对接 |
| 归航站 | 入口气闸控制台 E 返回停靠飞船；六条放射走廊、A–F 中央枢纽（放气门走近 9 米自动分两扇滑开）、约 490 米贯通长轴指挥塔与能源核心、72 间舱室与真实舷窗 |

篝火边按 E 取出棉花糖，火候条走到金黄时再按 E 取下，可补满氧气与燃料。

## 手机 / 触屏

- 手机浏览器会自动显示触屏层，无需额外设置；也可在地址后加 `?touch=1` 强制开启。
- 左侧摇杆移动 / 飞船平移，右侧空白拖动视角；右侧圆钮会根据徒步或飞船自动切换。
- 飞船圆钮：起飞 / 着陆 / 离船 / 上升 / 下降 / 加力 / 制动 / 自动航行；对接后切换为「进入空间站 / 脱离对接」。
- 站内使用「互动」按钮在中央枢纽气闸控制台返回飞船；左侧摇杆在六条放射走廊内移动。
- 星图右下角提供缩放、设为目标和关闭按钮，空白处拖动平移。
- 首次触摸会请求全屏并尝试锁定横屏，左上角「横屏全屏」按钮可手动重试；竖屏会被遮罩拦住，转到横屏后自动进入。
- Android Chrome 可强制横屏；iOS Safari 不允许网页锁定方向，需要手动旋转。

## 技术

- Godot 4.7.1（Compatibility / WebGL2，单线程导出，无需 COOP/COEP 头）
- 归航站的站内碰撞只保留当前所在走廊：玩家在站内时 1,464 → 244 个碰撞形状，其余五条走廊的碰撞随渲染一起退出物理世界（枢纽地板与门扇碰撞常驻）；走廊从半径 30 开始而"按朝向选走廊"只在半径 ≤26 内生效，半径 26~34 踩的是枢纽地板，因此不会把自己脚下的地板关掉
- 归航站的静态硬表面在启动时合并：走廊 1,497、枢纽 802、站外（外臂/主塔/端舱/检修车）1,403、外环细节 212 个 `MeshInstance3D` 按"材质签名 + 空间分块"烘焙成多材质网格（24 米 / 站外 60 米一块，六条走廊共享同一批资源）。全站网格节点 11,655 → 722、surface 11,660 → 2,636，飞到站点附近可绘制批次约 1,630 → 680。分块是为了灯光：兼容渲染器每个对象默认只能吃 8 盏灯，整条 213 米走廊合成一个对象会让门口发黑，因此长盒子按 24 米切段并把每对象灯上限提到 16。合并逐面核对了三角形数（与"含切段的预期值"完全相等）与法线长度，headless A/B 显示建场耗时 3,549 / 3,537 ms，几乎不变；碰撞、灯光、标签、旋转外环、可隐藏端舱与闪烁信标不受影响
- `index.wasm` 原始约 38 MB，gzip 后实际传输约 10.2 MB；`index.pck` 约 559 KB（591,328 字节）
- 已启用 Service Worker：首次加载后 wasm 会缓存到本地，第二次进入不再下载 wasm，只更新约 0.8 MB 的脚本与 pck
- 校园网限速时首次建议用流量/热点，或部署到 Cloudflare Pages / 国内对象存储
- 星球、地形、建筑、洞穴、量子规则与程序音频均为项目内程序化生成；环境音分深空床、站内底噪、行星风与远距无线电/金属应力单发，并走独立混响总线；枢纽放气门另有程序合成的位置音效（泄压嘶声 + 电机低鸣 + 到位顿挫），挂在门框上按距离衰减
- 网页版由浏览器控制分辨率与垂直同步；音频需首次点击后播放
- 网页版鼠标视角按 devicePixelRatio 归一化并乘 0.5 基础比例，单次事件限幅 120 px，避免指针锁定跳变导致高敏旋转
- 设置菜单支持画质预设、分辨率、帧率上限（30–240）、MSAA、阴影、视距、草地、主音量与鼠标灵敏度

- **素材**：未使用任何第三方 3D 模型、贴图、HDRI 天空盒或音频采样。星球、地形、洞穴、建筑、归航站、家具、飞船、星云、太阳与音效均由代码或着色器程序化生成。
- **灵感**：太空探索与时间循环类型（包括 Outer Wilds）带来类型与体验层面的启发（限时轮回、恒星爆发、量化观测、篝火烤棉花糖等玩法母题）。未使用其名称、角色、剧情、地点、界面、模型、文本、音乐或音效；十颗天体名（青岚星 / 赭崖星 / 沧波星 / 悬晶星 / 玄渊星 / 白曜星 / 磐砂星 / 苔垣星 / 硫坞星 / 缄默星）与舱室名均为原创。
- **空间站外观**：分段环舱、六条放射栖息臂、中央球状枢纽，以及约 490 米上下贯通的指挥塔与笼架能源核心；视觉组织参考《星际穿越》的环形空间站/Endurance；未使用其名称、标志、角色、剧情、模型、贴图或镜头，归航站的几何与标牌均为原创重建。
- **空间站布局**：中央枢纽 + 六条放射走廊 + 每廊十二舱室/大厅/舰桥的母题参考 Arknights 罗德岛等移动舰船的视觉组织方式；归航站、A–F 扇区名、72 间舱室、中央大厅、舰桥及全部标牌均为原创，未使用其名称、标志、角色或素材。六条栖息臂的外壳是"开口方管"（只有朝外的四个面），所以从枢纽的六扇门能直接看进走廊，站外看外壳依旧完整、舷窗照旧能看到真实星空。硬表面细节（双层墙板、螺栓、格栅、线槽、管线、放气门液压杆、门槛警示条、升降梯与全息沙盘，以及枢纽内 721 个盒子的甲板分缝/排水格栅/天花桥架/管束/灯具外壳/环墙竖肋/检修格栅/扶手/接线箱/门柱软管，合并为一张 8 材质网格）均由项目代码生成。
- **美术**：程序化低多边形、自定义星空/星云/太阳着色器、代码绘制 UI 与原创调色；无描摹或复用第三方画面。
